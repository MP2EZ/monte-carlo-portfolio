4 points

What holds it together

MODEL_TICKERS is the root key

Correlation order, CSV columns, JSON keys and the position of each random draw all follow it. tools/check_consistency.py checks that they agree.

The strategy key is the glide

A key such as 168>168+30:bnd_only@60>168@70 spells out the waypoints and also indexes results, so there is no separate glide table.

Provenance copies, it does not reference

The investor file and the parameters can change after a run. The record keeps the values that run used, which is how run.py --diff explains a change.

Paths are never stored

Pairing still rests on them. Every result in a run, and every return view, uses the same seeds and draws across all 27 tickers.
